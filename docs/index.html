Xcratch + UIAPduino
UIAPduino をブロックで動かす

290 円のマイコンボード UIAPduino（CH32V003）を、 ブロックをならべるだけで動かせます。 Xcratch という Scratch 3.0 互換のエディタに読み込ませて使う拡張機能です。 Arduino IDE は要りません。

Xcratch で開く →
押すと拡張機能を読み込んだ状態で Xcratch が開きます。

できること

ブロックはすべて実機で確認済みです。

LED・ピンの出力 スイッチの入力 アナログ値 A0〜A3 PWM サーボ 距離計 HC-SR04 NeoPixel WS2812B シリアル通信 キーボード マウス スケッチの書き込み

キーボードとマウスのブロックは、UIAPduino が USB キーボード・USB マウスとして パソコンを操作するものです。Scratch のステージの中だけでなく、 メモ帳や他のアプリが実際に動きます。

アナログ値の A0 の値〜A3 の値 はチェックを入れると ステージに 4 つ並び、緑の旗を押していなくても更新されます。

使い方

  1. Chrome か Edge で Xcratch を開きます。 上の「Xcratch で開く」を押すと、拡張機能を読み込んだ状態で開きます。 自分で読み込むときは、Xcratch の「拡張機能を追加 → Extension Loader」に 次の URL を入れます。 https://tarosay.github.io/scratch3-uiapduino/uiapduino.mjs
  2. 基板を書き込みモードにします。 基板のボタンを押しながら USB ケーブルを挿し、すぐにボタンを離します。
  3. パレットの末尾にある スケッチ (プロトコル 8) を書き込む をクリックします。 デバイス選択のダイアログに 32V003 が出るので、それを選びます。 進み具合は 書き込みの ようす に出ます。 焼き終わると基板は自動で繋ぎ直ります。
  4. あとはブロックをならべるだけです。
⚠ ブロックは直接クリックしてください。 緑の旗では書き込めません。
⚠「UIAPduino への接続が失われました」と出たら、× で閉じてください。 ケーブルを抜いたときに出るもので、焼き終わって繋がり直しても残ります。

書き込まれるのは拡張機能に同梱してあるスケッチなので、 拡張機能とスケッチの版が食い違うことはありません。 プロトコルが合わないと言われたときも、その画面から焼き直せます。

必要なもの

  • UIAPduino Pro Micro CH32V003 と USB ケーブル
  • Chrome か Edge。WebHID API を使うので Firefox と Safari では動きません

それ以外に必要なものはありません。インストールもアカウントも不要です。

Linux で使うとき

Linux では udev ルールの追加が要ります。 無いとブラウザが基板を開けず、デバイス選択のダイアログに出てこなかったり、 選んでも繋がらなかったりします。Windows と macOS では要りません。

/etc/udev/rules.d/99-minichlink-uiap-hid.rules を作って、 README の手順 のとおりに 4 行を書き、読み込ませてからブラウザを更新してください。

⚠ VID:PID は 2 組あります。 通常のスケッチで動いているときは 1209:d004、 書き込みモードでは 1209:b803 です。 d004 だけを書くと、ブロックは動くのに書き込みだけが失敗します。

デスクトップ版もあります

Scratch Desktop に組み込んだ版もあります。ブロックの実装は Xcratch 版と同じものを 共有しています。Xcratch で保存した .sb3 をデスクトップ版で開けることも 確認済みです。作り方は GitHub リポジトリ にあります。

UIAPduino をブロックで動かす方法は、もう一つあります

URB Block Lab — ブロックをつなぐと Ruby になります

ブロックで組んだものが Ruby のコードになり、基板の中で動きます。 こちらは Xcratch ではなく専用のページで、動かすには EEPROM（CAT24M01WI）も必要です。

URB Block Lab を開く

UIAPduino をブラウザから動かすページは UIAPduino WebHID Lab にまとまっています。Arduino IDE のセットアップ手順もそちらにあります。
